# ADR-006：Agent Alpha 不产生真实交易副作用

- 状态：Accepted
- 日期：2026-08-23

## 背景

KLineChartQuant 面向交易者，"让 Agent 直接下单"是显而易见的下一步诉求。但下单、撤单、
资金划转和账户操作属于**不可撤销的外部副作用**，与图表操作有本质区别：图表写操作可以
撤销并验证后置状态，一笔成交不能。

Agent Alpha 的可靠性证据目前只覆盖到图表与指标层面。

## 决策

Agent Alpha **不提供任何真实交易能力**。具体地：

- 不注册下单、撤单、转账、账户资金相关工具。
- 不提供无人监督的自动交易。
- system prompt 明确声明"MVP 不提供真实下单能力，也不得暗示已经交易"。
- 工具 safety 分类中的 `external-side-effect` 在 Alpha 保持为空集合。

交易能力属于**后续独立信任域**，需要自己的权限模型、审计、风控与确认流程，不能复用
图表工具的可撤销假设。

## 后果

正面：

- Agent 的失败模式上限是"图表状态不对"，而不是"资金损失"。
- 权限模型可以先在低风险域打磨成熟，再扩展到高风险域。
- 不需要在 Alpha 阶段处理券商集成、合规与资金安全问题。

负面：

- 与"超越 TradingView"的完整叙事相比，Alpha 明显缺少交易闭环。
- 用户可能期待 Agent 能下单，需要在 UI 与文档中明确说明边界。

## 何时重新评估

满足以下全部条件后再开启新的 ADR 讨论交易能力：

1. 确定性与 live 套件在图表域长期稳定达标。
2. 存在独立于图表工具的交易权限域与强制确认流程。
3. 具备券商 read-only 账户视图与完整审计链。
